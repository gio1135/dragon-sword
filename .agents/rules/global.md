# Global formatting & text rules

Critical: You must always adhere to the following rules for this project:

- **Code comments**: Do not write code comments. Never add them. Never delete existing comments, because they have been manually added. (Note: Exception to this rule during the initial addon rework only)
- **Code format**:
  - Always use 2 space indentation unless the actual code itself requires specific formatting
  - Never leave trailing whitespace
  - Never leave empty lines at the end of files
- **User facing text**: All user-facing text must be sentence case (e.g., "Manage land claim settings" instead of "Manage Land Claim Settings")
- **Punctuation**:
  - Always use a question mark at the end of a question
  - Never use exclamation points
  - Only use periods between sentences. If there is only one sentence, do not use a period. If there are multiple sentences, omit the period on the last sentence
