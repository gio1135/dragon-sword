# Loot tables

This document outlines how we modify vanilla loot tables to inject custom economy items, currency, or rebalance drops

## Jigsaw structures (vaults)
- Ominous vaults / vaults: We will inject these into standard vanilla structures (e.g., pillager outposts, desert temples, end cities) using jigsaw structure overrides
- Loot: They should contain high-value currency, rare enchantments, or unique builder materials to reward the explorer archetype

## Fishing
- Fishing can be a source of early-game passive income
- Modifications: Add a small chance to fish up economy currency or rare artifacts

## Villagers
- Modifications: Custom trades for the wandering trader or specific villager professions (like the custom trades added to the librarian)
